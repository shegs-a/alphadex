# API Documentation

Home for AlphaDex Scout's API contracts. The API is a FastAPI application; once
implemented it also serves interactive OpenAPI docs at `/docs`.

Planned resources (designed per-sprint, not built speculatively):

- `/health` — application / database / provider / pipeline health (Sprint 01)
- `/assets` — asset universe
- `/market-data`, `/fundamentals`, `/tokenomics`
- `/opportunities`, `/scores`, `/divergences`, `/risk`

> Status: placeholder (Sprint 00). Each endpoint's contract is documented here when
> the endpoint is implemented, starting with `/health` in Sprint 01.
